Data: the typical meteorological year for Turin, `data/processed/weather_turin_tmy.csv`
(source: PVGIS, European Commission JRC; see `data/processed/README.md`). Load it with
`energy_training.data.weather.load_tmy()`: SI units, temperatures in K, one continuous year
of hourly values in UTC.

## Instructions

The step-by-step instructions are in the notebook, next to the cells you complete. In short:

1. Run all the cells once. The first cell that uses a function you have not completed stops with
   `NotImplementedError`: read the message and the line in the traceback.
2. Complete `daily_stats()`: daily mean of `T_amb` and daily horizontal irradiation
   $H_h \approx \sum G_h\,\Delta t$ with $\Delta t$ = 3600 s (each hourly value stands for its
hour), converted from J/m² to kWh/m². Days run from 00:00 to 24:00 UTC.
3. Complete `coldest_and_sunniest()` and `monthly_irradiation()`.
4. Run the notebook. Check: the sum of the twelve monthly values equals the sum of the daily values.
   Which month has the most irradiation? June has the longest days: list two reasons why
   another month can still receive more (think of the weather, and of how a TMY is built; see
   `source_year`).
5. In a terminal at the course folder, run `uv run pytest`. It must end with a line like
   `NN passed`.

Before the self-check, run *Kernel → Restart Kernel and Run All Cells…*.
