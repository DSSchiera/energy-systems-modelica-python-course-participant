# G3.1 — M02 from library components

| | |
|---|---|
| **Learning objective** | compose a physical model from Modelica Standard Library components with `connect`, and verify it against an independent implementation |
| **Prerequisites** | Session 2 (M02 equations and schematic); Session 3 §4.3 (connectors) |
| **Starting files** | `exercises/session_03/S03_G1_ZoneRC_start.mo` (OMEdit), `exercises/session_03/s03_g1_compare.ipynb` (JupyterLab) |
| **Expected duration** | 20 min |
| **Expected outcome** | largest deviation from the Python M02 below 0.01 K for both temperatures |

## Instructions

1. Open `S03_G1_ZoneRC_start.mo` in OMEdit. It declares the M02 parameters (Bacher and Madsen 2011,
   Table 3) and the two heat capacities, both starting in equilibrium with a 1 kW heater at 0 °C.
2. **Before changing anything**, open the notebook `s03_g1_compare.ipynb` in JupyterLab and run
   it: it simulates the starting file with OpenModelica and compares it with the Python M02.
   The model simulates, but the deviation is about 16 K. Why does an unconnected model simulate at
   all? (Hint: what is the value of a flow variable at a port with no connection?)
3. Declare the missing components from `Modelica.Thermal.HeatTransfer`: two `ThermalConductor`
   (zone–envelope $G = 1/R_{ze}$, envelope–ambient $G = 1/R_{ea}$), a `FixedHeatFlow` heater
   ($\dot Q$ = 4 kW from $t = 0$) and a `FixedTemperature` ambient (0 °C). Read the source of
   `FixedHeatFlow` first: which sign does it use?
4. Connect them so that the network is the M02 schematic of Session 2. Save the file under a new
   name in `exercises/session_03/`, write the name in the notebook and rerun that cell until it
   prints `PASS`.
5. Print the flat model (next cell of the notebook) and count unknowns and equations. Which
   equations did each `connect` create?

## Extension activity

M02 sends all losses through the envelope. Write `EnvelopeRCWindow`, which **extends**
`EnergyTraining.Components.EnvelopeRC` and adds a conductance $UA_{win}$ (windows, ventilation)
directly from `port_a` to `port_b`. Use it in a model that extends
`EnergyTraining.Systems.ThermalZone` with `redeclare`. With a 4 kW heater and 0 °C outside, which
temperature should the zone reach after a long time? Check it by simulation.
