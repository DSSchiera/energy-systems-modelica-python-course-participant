# G1.1 — Step response and time constant (guided)

| | |
|---|---|
| **Learning objective** | Read τ and $T_{ss}$ from a simulated step response and relate them to $C$ and $UA$ (session outcomes 4–5). |
| **Prerequisites** | Lesson §5 (step response, τ, $T_{ss}$); explicit Euler from the guided example. |
| **Starting files** | `exercises/session_01/s01_g1_step.ipynb` (open it in JupyterLab) |
| **Expected duration** | 15 min |
| **Expected outcome** | τ estimated from the plot within 2 % of $C/UA$; $T_{ss}$ within 0.05 K of $T_{amb} + \dot Q/UA$. |

Parameters for this exercise (illustrative): $C = 8.0\cdot10^6$ J/K, $UA = 250$ W/K,
$T_{amb} = -5$ °C, $\dot Q = 6$ kW, $T_0 = 12$ °C.

## Instructions

The step-by-step instructions are in the notebook, next to the cells you complete. In short:

1. Compute $\tau$ and $T_{ss}$ by hand before coding.
2. Complete `rhs()` (energy balance, SI units).
3. Simulate 5 days with explicit Euler, $h$ = 10 min (provided).
4. Complete `estimate_tau()`: τ as the time at which 63.2 % of the step is reached; $T_{ss}$ as the
   final value. Run the self-check.
5. Which of the two estimates is more sensitive to the simulation length? Why?
6. Repeat with $h$ = 12 h. What happens to the τ estimate and why?

Before the self-check, run *Kernel → Restart Kernel and Run All Cells…*.

## Extension activity

Add Gaussian noise (σ = 0.1 K) to the simulated temperature and estimate τ by a linear fit of
$\ln|T - T_{ss}|$ against $t$ over the first $2\tau$. How much data do you need for 5 % accuracy?
