# Dynamic Modelling, Modelica and Techno-Economic Optimization of Energy Systems

Participant material for the course: 8 sessions × 2.5 h (20 h), plus Session 0, Python 101 (2.5 h).
Sessions are added here as the course progresses; see `EXPORT_INFO.md` for what is released.

**Start here:** install the software with [SETUP.md](SETUP.md) before Session 0 (Python 101).
The Session 0 guide, [course/session_00_python_101/guide.md](course/session_00_python_101/guide.md),
is the reference for the session and for review.

## Contents

| Folder | What it contains |
|--------|------------------|
| `course/` | lesson notes per session (`lesson.md`; Session 0: `guide.md`), common errors, optional topics |
| `slides/` | slides per session (`.pptx`, and the Markdown source) |
| `exercises/` | exercise sheets and starting files |
| `python/notebooks/` | notebooks used during the sessions |
| `python/src/energy_training/` | the course Python package (models, simulation, plotting) |
| `python/tests/` | tests of the course package (`uv run pytest`) |
| `modelica/EnergyTraining/` | the course Modelica library (open `package.mo` in OMEdit) |
| `figures/generated/` | figures used in lessons and slides, generated by code |
| `data/processed/` | input data of the case study (weather of Turin), with source and licence |
| `docs/` | course overview, syllabus, learning outcomes, prerequisites, notation |
| `REFERENCES.md` | sources cited in the material as `[src: id]` |

Course map: [docs/course_overview.md](docs/course_overview.md) ·
[docs/syllabus.md](docs/syllabus.md) · notation: [docs/notation.md](docs/notation.md).
