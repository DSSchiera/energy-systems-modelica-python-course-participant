# Prerequisites

The participant is an engineering/technical researcher. The course assumes the items in
**Required**; items in **Refresher provided** are briefly revisited in the course or in a
pre-reading note, because they are likely gaps for this audience.

## Required

| Area | Level |
|------|-------|
| Calculus | derivatives, integrals, first-order linear ODEs |
| Linear algebra | matrices, vectors, eigenvalues (conceptually) |
| Physics | heat, temperature, energy, power; first law of thermodynamics |
| Python | basic programming in any language; the Python needed is covered by Session 0 |
| Computing | installing software, using a terminal |

## Refresher provided (in the course or as pre-reading; Session 0 is the largest part)

| Topic | Why | Used in |
|-------|-----|---------|
| Enthalpy, $c_p$, open-system energy balance | needed for fluid flows | S2, S5 |
| Python 101: environment, notebooks, NumPy, pandas, Matplotlib | all sessions | S0 (contact session, 2.5 h) |
| Discounting and the time value of money | techno-economic assessment | S7 |
| Linear programming in one page | dispatch and sizing | S8 |

## Not required

- Prior Modelica, OpenModelica or FMI experience.
- Control theory (operation is rule-based or optimized; no feedback design is taught).
- Fluid mechanics beyond $\Delta p \propto \dot m^2$.

## Before Session 0

Install the software with [SETUP.md](../SETUP.md) up to "open the notebooks", and check that every step ends without errors (OpenModelica can wait until Session 3).
Installation problems are the most common cause of lost time in the first sessions.
